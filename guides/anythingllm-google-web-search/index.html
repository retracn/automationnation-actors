Google web search for AnythingLLM agents (through the SearXNG option)

AnythingLLM's web-browsing agent skill can search through a SearXNG instance, and it accepts any URL that answers like SearXNG's JSON API. Google Custom Search API Alternative on Apify has such a route, so pasting https://automationnation--google-custom-search-api.apify.actor/searxng?token=YOUR_APIFY_TOKEN as the SearXNG API Base URL gives your agents Google's web results, without hosting SearXNG and without a Google API key. Each page of up to 10 results costs $0.005. The route was tested on 6 October 2026 with the same request AnythingLLM sends.

Open Google Custom Search API Alternative on Apify $5 per 1,000 searches of up to 10 results ($4 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com and copy your API token from Settings → API & Integrations. The free plan's $5 monthly credit covers about 1,000 searches.
  2. Open the web search skill. In AnythingLLM, go to Settings → Agent Skills → Web Search and choose SearXNG as the search provider.
  3. Paste the URL. SearXNG API Base URL: https://automationnation--google-custom-search-api.apify.actor/searxng?token=YOUR_APIFY_TOKEN (or set AGENT_SEARXNG_API_URL to it). AnythingLLM adds q and format=json itself.
  4. Ask your agent. In a workspace chat, start with @agent and ask for something that needs the web, for example the latest on a topic. The agent's search returns Google's top 10 results.
  5. Optional: country and language. Add &gl=gb (country) or &language=en-GB to the URL to localise results.

Alternatives

AnythingLLM also supports Google's own Programmable Search Engine (its Custom Search JSON API is closed to new customers and ends on 1 January 2027), SearchApi, Serper, Brave, Tavily, Exa, DuckDuckGo and a self-hosted SearXNG, which is free but needs a server.

FAQ

Is this a real SearXNG instance?

No. It answers in SearXNG's JSON format, with Google as the only engine, so tools built for SearXNG can read it.

Is putting the token in the URL safe?

It's stored like any other API key in AnythingLLM's settings. Use a token from your own Apify account, and you can rotate it in Apify Console at any time.

What does it cost?

$5 per 1,000 searches of up to 10 results ($4 on Gold and above). Searches that return nothing are free.

Does it work with Open WebUI?

Yes, but use Open WebUI's External engine instead, with the /search route and your token as the key. There's a separate guide for that.
