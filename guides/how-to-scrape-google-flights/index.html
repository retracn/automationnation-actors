How to scrape Google Flights in 2026 (prices, airlines and times)

Google shut down its flights API in 2018, so the practical way to get Google Flights data is a scraper. With Google Flights Scraper on Apify you enter the route and date, click Start, and get every flight option with price, airlines, flight numbers, times, stops and CO2 in seconds, for $0.20 per 1,000 flights.

Open Google Flights Scraper on Apify $0.20 per 1,000 flights ($0.16 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, about 25,000 flights with this Actor, and needs no credit card.
  2. Open Google Flights Scraper. Go to apify.com/automationnation/google-flights-scraper and click Try for free.
  3. Set the route. Enter From and To (airport codes or cities) and the departure date; add a return date for round trips, or many routes at once.
  4. Choose options. Cabin, adults, stops and currency.
  5. Track fares. Schedule daily runs and alert on price drops through Apify integrations.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-flights-scraper").call(run_input={
  "origin": "JFK",
  "destination": "LHR",
  "departureDate": "2026-11-12"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("price"), item.get("airlines"), item.get("departure"), item.get("duration"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-flights-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"origin": "JFK", "destination": "LHR", "departureDate": "2026-11-12"}'

FAQ

Are prices per person?

They include taxes and cover all passengers; round trips show the round-trip total.
