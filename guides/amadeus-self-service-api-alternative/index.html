Amadeus Self-Service API shut down? Get flight and hotel prices by API in 2026

Amadeus switched off its Self-Service APIs on 17 July 2026: self-service keys stopped working, and apps built on Flight Offers Search and Hotel Search stopped getting data. Only Amadeus Enterprise, under a commercial agreement, remains. For flight and hotel prices, Google Flights Scraper and Google Hotels Scraper on Apify return Google's current fares and hotel prices through a REST API, with no partner agreement. Flights cost $0.20 per 1,000 results and hotels $1 per 1,000, so Apify's free $5 monthly credit covers about 25,000 flights.

Open Google Flights Scraper on Apify $0.20 per 1,000 flights ($0.16 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit and needs no credit card. Copy your API token from Settings → Integrations.
  2. Replace Flight Offers Search. POST to https://api.apify.com/v2/acts/automationnation~google-flights-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN with {"origin": "MAD", "destination": "ATH", "departureDate": "2026-11-12", "adults": 1}. originLocationCode and destinationLocationCode become origin and destination, travelClass becomes cabinClass, and nonStop=true becomes stops: "nonstop".
  3. Or keep your Amadeus SDK code (Node). npm install github:retracn/amadeus-cloud, then require('amadeus-cloud') instead of require('amadeus') and set APIFY_TOKEN. amadeus.shopping.flightOffersSearch.get() and .post() take the same parameters and return Amadeus-shaped flight offers built from these fares.
  4. Read the results. Each row is one flight option, with price (all passengers, taxes included), airlines, flight numbers, times, stops, layovers and legs[], which takes the place of Amadeus's itineraries[].segments[].
  5. Replace Hotel Search. POST to the google-hotels-scraper endpoint with {"locations": ["Paris"], "checkIn": "2026-11-12", "checkOut": "2026-11-15", "adults": 2}. You get up to 20 hotels per search, with nightly prices with and without taxes, the stay total, star class, rating and coordinates.
  6. Search several routes in one call. Pass routes, for example ["JFK-LHR 2026-11-12", "JFK-CDG 2026-11-12"], to search many routes and dates in one run, or schedule daily runs for price alerts.
  7. Use it from an AI agent. Travel assistants built on MCP can add https://mcp.apify.com?tools=automationnation/google-flights-scraper,automationnation/google-hotels-scraper and sign in with Apify.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-flights-scraper").call(run_input={
  "origin": "JFK",
  "destination": "LHR",
  "departureDate": "2026-11-12"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("price"), item.get("airlines"), item.get("departure"), item.get("duration"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-flights-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"origin": "JFK", "destination": "LHR", "departureDate": "2026-11-12"}'

FAQ

When did the Amadeus Self-Service APIs shut down?

Amadeus paused new self-service registrations in spring 2026 and fully decommissioned the portal on 17 July 2026; self-service API keys were disabled that day. The Enterprise APIs are not affected.

Are the prices bookable?

No. They're the prices Google Flights and Google Hotels show at the time of the run, with links to the results. There's no price confirmation, seat map or booking step, so book through the airline, hotel or an agency.

Can I search with city names instead of IATA codes?

Yes. Flights accept airport codes or city names, such as London to New York, which searches every airport Google groups under each city.

What does it cost?

Flights cost $0.20 per 1,000 results ($0.16 on Gold and above) and hotels $1 per 1,000. A search returns 10–30 flights or up to 20 hotels, so a search costs under a cent or two. Failed searches are free.

Does it support children, infants or multi-city trips?

Not yet: searches take adults, cabin class and stops, one way or round trip.
