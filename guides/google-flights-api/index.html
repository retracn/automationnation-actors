Google Flights API in 2026: is there one, and how to get flight prices by API

Google has no public Google Flights API. It shut down QPX Express, the flight search API behind Google Flights, on 10 April 2018 and never replaced it, and Google Flights' partner programs are for airlines and online travel agencies. Amadeus also switched off its free Self-Service APIs in July 2026. To get Google Flights results by API, Google Flights Scraper on Apify returns the fares Google Flights shows for any route and date as JSON: price, airlines, flight numbers, times, stops, layovers, aircraft and CO2. It costs $0.20 per 1,000 flights.

Open Google Flights Scraper on Apify $0.20 per 1,000 flights ($0.16 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, about 25,000 flights, and needs no credit card. Copy your API token from Settings → Integrations.
  2. Search a route. POST to https://api.apify.com/v2/acts/automationnation~google-flights-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN with {"origin": "JFK", "destination": "LHR", "departureDate": "2026-11-12"}. The response is a JSON array with one object per flight option.
  3. Round trips, cabins and stops. Add returnDate for a round trip (prices become round-trip totals), cabinClass for premium economy, business or first, adults for more passengers, and stops: "nonstop" for direct flights only.
  4. Many routes and dates in one call. Pass routes, for example ["JFK-LHR 2026-11-12", "JFK-CDG 2026-11-12", "JFK-LHR 2026-11-13"], to compare airports or dates in one run.
  5. Set currency and market. currency sets the price currency and country the Google market, for example GBP and gb.
  6. Automate it. Schedule a daily run for price alerts, send results to Slack, Sheets or a webhook through Apify's integrations, or give an AI agent the MCP server URL below.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-flights-scraper").call(run_input={
  "origin": "JFK",
  "destination": "LHR",
  "departureDate": "2026-11-12"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("price"), item.get("airlines"), item.get("departure"), item.get("duration"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-flights-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"origin": "JFK", "destination": "LHR", "departureDate": "2026-11-12"}'

FAQ

Is there an official Google Flights API?

No. QPX Express, which gave developers Google's flight search, closed on 10 April 2018 and wasn't replaced. Google works with airlines and travel agencies as partners, but there's no public search API.

Are these the same prices as on Google Flights?

Yes. They're the fares Google Flights shows for that search at the time of the run, including taxes and fees, with a link back to the results.

Can I book flights through it?

No. It returns prices and flight details, not bookable offers. Use a booking API or the airline's site to book.

How fast is it?

It uses plain HTTP requests, not a browser, so a search usually returns in seconds.

What does it cost?

$0.20 per 1,000 flights ($0.16 on Gold and above). A search returns 10–30 flights, so it costs under a cent, and failed searches are free.
