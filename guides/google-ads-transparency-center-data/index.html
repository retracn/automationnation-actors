How to see a competitor's Google ads (Ads Transparency Center data)

Google's Ads Transparency Center lists the ads verified advertisers run, but only one at a time in a browser. Google Ads Transparency Scraper on Apify returns them all as data: enter a domain or brand, click Start, and get each ad's format, first and last shown dates, days running and ad text, for $1 per 1,000 ads.

Open Google Ads Transparency Scraper on Apify $1 per 1,000 ads ($0.80 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, about 5,000 ads with this Actor, and needs no credit card.
  2. Open Google Ads Transparency Scraper. Go to apify.com/automationnation/google-ads-transparency-scraper and click Try for free.
  3. Add advertisers. Enter domains (nike.com), names (Nike) or advertiser IDs (AR…).
  4. Filter by country and format. Pick a country and text, image or video ads.
  5. Spot their winners. Sort by days running: ads live for months are usually the ones that work.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-ads-transparency-scraper").call(run_input={
  "advertisers": [
    "nike.com"
  ],
  "region": "us",
  "maxAdsPerAdvertiser": 100
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("advertiserName"), item.get("format"), item.get("headline"), item.get("daysShown"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-ads-transparency-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"advertisers": ["nike.com"], "region": "us", "maxAdsPerAdvertiser": 100}'

FAQ

No, Google only publishes spend for political ads.
