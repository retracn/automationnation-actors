JobSpy Google Jobs not working? "Google Jobs is currently unavailable" fixed with one import

JobSpy's README says "Google Jobs is currently unavailable": Google now serves job data only to browsers that run JavaScript, so site_name="google" returns an empty DataFrame, and the logs show "initial cursor not found". jobspy-google is a drop-in scrape_jobs with the same arguments and the same 34 DataFrame columns. "google" runs on Google Jobs Scraper on Apify, which renders Google Jobs in a real browser, and every other site is passed to JobSpy unchanged. Google results cost $0.03 per search plus $2 per 1,000 jobs.

Open Google Jobs Scraper on Apify $2 per 1,000 jobs ($1.50 on paid plans) + $0.03 per search

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit and needs no credit card. Copy your API token from Settings → Integrations and set APIFY_TOKEN.
  2. Install the drop-in. pip install git+https://github.com/retracn/jobspy-google. It installs python-jobspy too.
  3. Change one import. Replace from jobspy import scrape_jobs with from jobspy_google import scrape_jobs. Keep your arguments: site_name, search_term, google_search_term, location, results_wanted, hours_old, is_remote, job_type, country_indeed and offset.
  4. Mix sites as before. site_name=["indeed", "linkedin", "google"] runs Indeed and LinkedIn in JobSpy and Google through the hosted API, then returns one DataFrame sorted by site and date, like JobSpy.
  5. Use the Google columns. Google rows fill title, company, location, date_posted, job_type, salary (interval, min_amount, max_amount, currency), is_remote, description and the apply link in job_url.
  6. Or call the Actor directly. For extra fields JobSpy doesn't have (the job board each listing came from, qualifications, benefits, every apply link), call Google Jobs Scraper itself.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-jobs-scraper").call(run_input={
  "queries": [
    "software engineer"
  ],
  "location": "New York",
  "country": "us",
  "maxJobsPerQuery": 50
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("title"), item.get("companyName"), item.get("salaryText"), item.get("applyUrl"))

FAQ

Why does JobSpy return no Google jobs?

Google Jobs now loads its listings with JavaScript, and JobSpy fetches pages without a browser, so the job data never arrives. Proxies or different search terms don't change that.

Is the DataFrame the same?

Yes: the same 34 columns in the same order, sorted by site and date. Columns Google doesn't provide, such as company_industry, stay empty, as they do for other sites.

Which countries work?

26 Google Jobs countries, including the USA, UK, Canada, India, Germany, Spain, Mexico, Singapore and the UAE, set with country_indeed as in JobSpy.

How fast is it?

About 20–60 seconds per Google search, since it uses a real browser.

What does it cost?

$0.03 per search plus $2 per 1,000 jobs ($1.50 on paid plans) on your Apify account. The other sites run in JobSpy at no extra cost.
