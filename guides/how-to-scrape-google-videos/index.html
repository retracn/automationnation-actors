How to scrape Google Videos results in 2026

Google Videos Scraper on Apify returns Google's Videos tab as data: enter a search, click Start, and get each video's title, URL, platform, channel, duration and date across YouTube, TikTok, Vimeo and more, for $1 per 1,000 videos.

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, about 5,000 videos with this Actor, and needs no credit card.
  2. Open Google Videos Scraper. Go to apify.com/automationnation/google-videos-scraper and click Try for free.
  3. Enter searches. Add searches plus country and language.
  4. Filter. Duration (short, medium, long) and time.
  5. Go further. Send YouTube URLs to YouTube Transcript Scraper for full transcripts.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-videos-scraper").call(run_input={
  "queries": [
    "how to make sourdough bread"
  ],
  "maxResultsPerQuery": 30
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("title"), item.get("channel"), item.get("duration"), item.get("url"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-videos-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["how to make sourdough bread"], "maxResultsPerQuery": 30}'
