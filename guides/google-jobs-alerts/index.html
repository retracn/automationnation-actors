Google Jobs alerts: get new job postings daily in Slack, email or Sheets

Google Jobs has no alerts API, and its own alerts only email signed-in users. To get new postings as data, run Google Jobs Scraper on Apify on a schedule with Only new jobs turned on. Each run searches Google Jobs, which collects listings from LinkedIn, Indeed, Glassdoor, company sites and other boards, and returns only jobs that weren't returned for the same search before, with salaries, full descriptions and resolved employer apply links. Jobs are remembered for 120 days and you pay only for new ones: $2 per 1,000 jobs plus $0.03 per search, so a daily check that finds 15 new postings costs about $0.06.

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan's $5 monthly credit covers a daily alert for over two months.
  2. Enter your job search. Open Google Jobs Scraper and add one or more searches ("data analyst", "python developer"), a location and the country. Filter by date posted, job type or remote.
  3. Turn on Only new jobs. Switch on Only new jobs (for scheduled runs). The first run returns everything that matches; later runs return only new postings.
  4. Save it as a task and schedule it. Click Save as a new task, then Schedule it every morning.
  5. Send the alerts. On the task's Integrations tab, send new jobs to Slack, email, Google Sheets or a webhook, or into n8n, Make or Zapier.

Do it from code

One check (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-jobs-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["python developer"], "location": "United States", "country": "us", "datePosted": "3days", "remoteOnly": true, "onlyNewJobs": true}'

# Each row: title, companyName, location, salaryText, salaryMin/Max, description, applyUrl (employer site first), postedAt, isNew

A daily job alert, set up through the API (cURL)

# 1. Save the search as a task
curl -X POST "https://api.apify.com/v2/actor-tasks?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"actId": "M8hKD5qslVXb8Z97r", "name": "remote-python-jobs", "input": {"queries": ["python developer"], "location": "United States", "country": "us", "datePosted": "3days", "remoteOnly": true, "onlyNewJobs": true}}'

# 2. Run it every morning (TASK_ID is the id returned by step 1)
curl -X POST "https://api.apify.com/v2/schedules?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name": "remote-python-jobs-daily", "cronExpression": "0 7 * * *", "timezone": "Europe/London", "isEnabled": true, "isExclusive": true, "actions": [{"type": "RUN_ACTOR_TASK", "actorTaskId": "TASK_ID"}]}'

Alternatives

LinkedIn and Indeed job alerts email signed-in users for their own listings only, with no API. JobSpy (the Python library) can scrape several boards but its Google Jobs source often returns nothing on servers. Paid job-data APIs such as Coresignal or TheirStack sell bulk feeds on monthly plans. See the side-by-side comparison.

FAQ

Which countries does it cover?

26, including the US, UK, Canada, India, Germany, Singapore, the UAE and Brazil; set the country and a location in it.

How does it know a job is new?

By Google's job ID, remembered per search for 120 days. If an employer reposts and Google lists it as a new job, it counts as new.

Can I run several searches in one alert?

Yes. Add several queries; each is remembered separately and charged $0.03 per search.
