Skyscanner API alternative: flight prices by API without a partner application (2026)

Skyscanner's API isn't open to the public: you apply to its partnerships team, and they get in touch only if they approve you. If you need flight prices for a side project, an internal tool, price alerts or an AI agent, Google Flights Scraper on Apify returns live Google Flights results by API with no application. You get price, airlines, flight numbers, times, duration, stops, layovers, aircraft, emissions and a Google Flights link for any route and date, at $0.20 per 1,000 flights. It returns search results; it doesn't book tickets.

Open Google Flights Scraper on Apify $0.20 per 1,000 flights ($0.16 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com and copy your API token from Settings → API & Integrations. The free plan's $5 monthly credit covers about 25,000 flights.
  2. Search a route. Call the Actor with origin, destination and departureDate (add returnDate for a round trip). Airport codes (LHR) and city names (London) both work.
  3. Set the market. currency (GBP, EUR, USD…) and country (gb, de, us…) set Google's point of sale, which can change prices.
  4. Filter. cabinClass (economy, premiumEconomy, business, first), adults, and stops (any, nonstop, oneStop).
  5. Many routes at once. Put extra searches in routes, one per line, e.g. "JFK-LHR 2026-11-12" or "LAX-NRT 2026-12-01 2026-12-15" for a round trip.
  6. Track prices. Save the input as a task and schedule it daily; each run adds today's prices, so you can alert on drops.

Do it from code

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-flights-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"origin": "LHR", "destination": "JFK", "departureDate": "2026-11-12", "returnDate": "2026-11-19", "adults": 1, "currency": "GBP", "country": "gb"}'

# Each flight: price, currency, airlines, flight numbers, departure and arrival times, duration,
# stops and layovers, aircraft and legroom per leg, CO2 vs typical, and a Google Flights link

Alternatives

Other options: apply for Skyscanner's partner API if you'll send it bookings; booking APIs such as Duffel, which are built to sell tickets and need an account with them; or fast-flights, a free Python library that reads Google Flights directly and works for light use. Amadeus switched off its Self-Service APIs on 17 July 2026. See the side-by-side comparison.

FAQ

Is this Skyscanner's data?

No. It's Google Flights: the prices from airlines and travel agencies that Google shows for the route and date. Prices can differ slightly from what Skyscanner shows.

Can I book through it?

No, it returns search results. Each flight includes a Google Flights link to book from.

What does it cost?

$0.20 per 1,000 flights ($0.16 on Gold and above) on your Apify account. A typical search returns 10–30 flights, under a cent.

Can an AI agent use it?

Yes. Add https://mcp.apify.com?tools=automationnation/google-flights-scraper to Claude, ChatGPT or Cursor, or use the search_flights tool in the AutomationNation MCP server.
