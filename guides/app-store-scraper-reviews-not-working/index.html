app-store-scraper reviews not working (403 or "Unexpected token <")? Get App Store reviews in 2026

Users of the Node package app-store-scraper report statusCode 403 and "Unexpected token < in JSON at position 0" from reviews(), the package hasn't had a release since version 0.18.0 in November 2023, and the Apple review feed it reads stops at 500 reviews (10 pages). The quickest fix is app-store-scraper-cloud, a drop-in replacement with the same API: change the require line, and reviews() runs on App Store Reviews Scraper on Apify, which reads Apple's current review endpoint and goes past 500 reviews. Outside Node, call the Actor directly. It returns rating, title, text, date, reviewer name, edit flag and developer replies, for $0.08 per 1,000 reviews.

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, roughly 60,000 reviews with this Actor, and needs no credit card.
  2. Switch the require line (Node). Run npm install github:retracn/app-store-scraper-cloud, then require('app-store-scraper-cloud') instead of require('app-store-scraper') and set APIFY_TOKEN. reviews() takes the same options (id or appId, country, sort, page) and returns the same fields; every other method is the original.
  3. Install the Apify client. Run npm install apify-client (or pip install apify-client) and copy your API token from Apify Console → Settings → API & Integrations.
  4. Add your apps. Pass App Store URLs, numeric App Store IDs (like 324684580) or app names in apps, and the storefronts you want in countries, for example ["us", "gb", "de"].
  5. Filter and sort. Set maxReviewsPerApp, sort (newest or most relevant) and minRating or maxRating, for example 1 to 2 stars to collect complaints only.
  6. Run and export. Start the run and read the dataset as JSON, CSV or Excel, or through the API. Each row is one review with the app's name, developer and overall rating attached.
  7. Monitor new reviews. Turn on onlyNewReviews and add a daily schedule to receive only reviews posted since the last run.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/app-store-reviews-scraper").call(run_input={
  "apps": [
    "https://apps.apple.com/us/app/spotify-music-and-podcasts/id324684580",
    "570060128"
  ],
  "countries": [
    "us",
    "gb"
  ],
  "maxReviewsPerApp": 1000,
  "sort": "newest"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("appName"), item.get("rating"), item.get("date"), item.get("title"))

FAQ

What does "Unexpected token < in JSON at position 0" mean?

The package expected JSON but received an HTML page, usually an error or block page from Apple. Users have reported it together with 403 responses when fetching reviews.

How many reviews can I get?

Apple's public review feed stops at about 500 reviews per country. The Actor reads further back, tens of thousands of reviews for popular apps.

Can I get reviews from several countries?

Yes. List the storefronts in countries; reviews are separate per country, and each row says which country it came from.
