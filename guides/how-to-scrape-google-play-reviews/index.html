How to scrape Google Play reviews in 2026 (no code, API or AI agent)

Google's Play Developer API only returns reviews for your own apps, from the last week. To get reviews of any app, Google Play Reviews Scraper on Apify reads the public reviews on Google Play: give it Google Play links, package names or app names, click Start, and get one row per review with stars, text, date, author, thumbs-up count, app version and the developer's reply, for $0.08 per 1,000 reviews.

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, over 60,000 reviews with this Actor, and needs no credit card.
  2. Open Google Play Reviews Scraper. Go to apify.com/automationnation/google-play-reviews-scraper and click Try for free.
  3. Add apps. Paste Google Play URLs, package names (e.g. com.spotify.music) or app names (e.g. Spotify), and set the country and language.
  4. Set the limit and filters. Choose Max reviews per app, the sort order (newest, most relevant or rating), and optionally a star range.
  5. Run and export. Click Start. Download JSON, CSV or Excel, or read the results through the API.
  6. Automate it. Tick Only new reviews and schedule the Actor daily, then send new reviews to Slack, email, Google Sheets or a webhook through Apify integrations.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-play-reviews-scraper").call(run_input={
  "apps": [
    "com.spotify.music",
    "Duolingo"
  ],
  "maxReviewsPerApp": 200,
  "sort": "newest",
  "country": "us",
  "language": "en"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("appName"), item.get("rating"), item.get("date"), item.get("text"))

FAQ

Can I get Google Play reviews in other languages?

Yes. Set language (en, de, es, fr, pt, ja, …) and country; each run reads that storefront's reviews.

Does it include developer replies?

Yes, replyText and replyDate whenever the developer replied.
