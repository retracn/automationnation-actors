Google Hotels API in 2026: how to get hotel prices from Google by API

Google has no public API for Google Hotels search results. Its hotel APIs, Hotel Center and the Travel Partner API, are for hotels and booking sites that send Google their own prices. Amadeus's free Self-Service hotel APIs were also switched off in July 2026. Google Hotels Scraper on Apify returns what Google Hotels shows for a city or area and your dates as JSON: nightly prices with and without taxes, the stay total, star class, rating, reviews, coordinates and photos. It costs $1 per 1,000 hotels.

Open Google Hotels Scraper on Apify $1 per 1,000 hotels ($0.80 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, about 5,000 hotels, and needs no credit card. Copy your API token from Settings → Integrations.
  2. Search a place and dates. POST to https://api.apify.com/v2/acts/automationnation~google-hotels-scraper/run-sync-get-dataset-items?token=YOUR_TOKEN with {"locations": ["Paris"], "checkIn": "2026-11-12", "checkOut": "2026-11-15", "adults": 2}.
  3. Filter the results. minRating keeps hotels rated 3.5, 4 or 4.5 and up, minHotelClass sets the minimum stars, and maxPricePerNight caps the nightly price.
  4. Read the prices. Each hotel has pricePerNight (before taxes), pricePerNightWithTaxes, estimatedStayTotal and currency, plus rating, reviewCount, hotelClass, latitude, longitude, photos and links.
  5. Search several places at once. Put several cities, neighbourhoods or searches in locations to compare them in one run.
  6. Automate it. Schedule runs to track prices for your dates, send results to Sheets or a webhook, or give an AI agent the MCP server URL below.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-hotels-scraper").call(run_input={
  "locations": [
    "Paris"
  ],
  "checkIn": "2026-11-20",
  "checkOut": "2026-11-23"
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("name"), item.get("pricePerNight"), item.get("rating"), item.get("hotelClass"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-hotels-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"locations": ["Paris"], "checkIn": "2026-11-20", "checkOut": "2026-11-23"}'

FAQ

Is there an official Google Hotels API?

Not for search results. Google's Hotel Center and Travel Partner APIs let hotels and booking sites send prices and read their own performance data.

Which prices are these?

Google Hotels' lowest price across booking sites for your dates: per night before taxes, per night with taxes and fees, and the estimated total for the stay.

How many hotels does a search return?

Up to 20 per search, Google Hotels' first page. Search neighbourhoods or add filters to cover more hotels.

Can I search near a landmark?

Yes. A location can be any search Google Hotels understands, such as Shoreditch, London or a landmark name.

What does it cost?

$1 per 1,000 hotels ($0.80 on Gold and above), so a 20-hotel search costs 2 cents.
