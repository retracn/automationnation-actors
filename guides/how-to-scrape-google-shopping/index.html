How to scrape Google Shopping in 2026 (prices, stores and reviews)

Google has no public API for Google Shopping results, so the practical way to get them is a ready-made scraper. With Google Shopping Scraper on Apify you enter a product search and country, click Start, and get about 50 products in seconds, each with price, discount, store, rating and reviews, for $1 per 1,000 products.

Open Google Shopping Scraper on Apify $1 per 1,000 products ($0.80 on Gold and above)

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan includes $5 of monthly credit, about 5,000 products with this Actor, and needs no credit card.
  2. Open Google Shopping Scraper. Go to apify.com/automationnation/google-shopping-scraper and click Try for free.
  3. Enter searches and a country. Add product searches such as "air fryer" and the country (us, gb, de…). Prices come in that country's currency.
  4. Run and export. Click Start and download JSON, CSV or Excel, or read the dataset through the API.
  5. Automate price monitoring. Schedule the Actor daily and send results to Google Sheets, Slack or a webhook through Apify integrations.

Do it from code

Python

# pip install apify-client
from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("automationnation/google-shopping-scraper").call(run_input={
  "queries": [
    "wireless earbuds"
  ],
  "country": "us",
  "maxResultsPerQuery": 50
})
for item in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(item.get("title"), item.get("price"), item.get("store"), item.get("rating"))

REST API (cURL)

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-shopping-scraper/run-sync-get-dataset-items?token=$APIFY_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"queries": ["wireless earbuds"], "country": "us", "maxResultsPerQuery": 50}'
