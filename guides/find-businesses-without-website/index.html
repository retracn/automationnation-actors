How to find local businesses without a website (from Google Maps), with phone numbers and a pitch

Google Maps Leads on Apify can return only the businesses whose Google Maps listing has no website: hair salons in Austin, plumbers in Leeds, cafés in Berlin. Each comes with its address, phone in international format, Facebook or Instagram link when listed, rating and review count, a lead score and a short outreach message pitching a website. Finding them means checking about ten listings for each one that qualifies, so each no-website business costs $0.08. Businesses that have a website are skipped for free.

Open Google Maps Leads Scraper on Apify $0.03 per lead ($0.024 on Gold); $0.08 per business found with the no-website or unclaimed filters

Step by step

  1. Create a free Apify account. Sign up at apify.com. The free plan's $5 monthly credit covers about 60 no-website leads.
  2. Pick the area and trade. Open Google Maps Leads, set cities (e.g. Austin, TX), country (us) and category (hair salon, plumber, café…).
  3. Turn on the no-website filter. Switch on "Only businesses without a website". Optionally also ask for unclaimed listings, or businesses that opened recently.
  4. Set how many. maxResults caps the number of leads, and you can set a maximum cost per run too.
  5. Export. Download the dataset as CSV or Excel, or send it to Google Sheets, HubSpot or a webhook.
  6. Check before you pitch. A business with no website on Google Maps may still have one elsewhere, so check quickly before you call. Follow the outreach rules where you are (for example PECR and GDPR in the UK).

Do it from code

REST API (cURL), straight to CSV

curl -X POST "https://api.apify.com/v2/acts/automationnation~google-maps-leads/run-sync-get-dataset-items?token=$APIFY_TOKEN&format=csv" \
  -H "Content-Type: application/json" \
  -d '{"cities": ["Austin, TX"], "country": "us", "category": "hair salon", "noWebsiteOnly": true, "maxResults": 20}' \
  -o leads.csv

# leads.csv: name, category, address, phone, Facebook/Instagram links, rating, reviews,
# Google profile score, HOT/WARM/COLD lead score and an outreach message pitching a website

Alternatives

You can search Google Maps by hand and note listings without a Website button: free, but slow. General Google Maps scrapers such as compass/crawler-google-places return every business, and you filter out the ones with websites yourself.

FAQ

Why does each lead cost $0.08?

Most listings have a website, so the Actor checks about ten listings to find each one without. You only pay for the businesses it saves; the rest are free.

Do I get email addresses?

Usually not: with no website there's no site to read an email from. You get phone numbers, addresses and social links when the listing has them.

Which countries work?

Any country Google Maps covers. UK searches can add Companies House director names through UK Business Leads.

Can I get new ones every week?

Yes: schedule the run with incremental mode on, and each run returns only businesses you haven't seen before.
