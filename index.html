Drop-in packages for broken libraries

Open source (MIT): change one import and keep your code; the data comes from these Actors.

  • pytrends-cloud (Python): replaces pytrends. Google Trends without 429 errors; same TrendReq API and pandas output.
  • youtube-transcript-cloud (Python): replaces youtube-transcript-api. YouTube transcripts from AWS, GCP, Azure and other servers; no RequestBlocked or IpBlocked.
  • youtube-transcript-cloud (npm): replaces youtube-transcript. YouTube transcripts that work in production on Vercel, AWS Lambda and Render; same API and errors.
  • google-trends-api-cloud (npm): replaces google-trends-api. No 429s from servers, and dailyTrends and realTimeTrends work again; same methods and JSON.
  • googlesearch-cloud (Python): replaces googlesearch-python. from googlesearch import search returns results again (Google stopped serving the page it parsed); same search() and SearchResult.
  • jobspy-google (Python): replaces JobSpy (Google Jobs). site_name="google" returns jobs again; same scrape_jobs arguments and DataFrame columns.
  • fast-flights-cloud (Python): replaces fast-flights. A fast-flights integration for when Google blocks you: same get_flights() and Flights objects, fetched by a hosted Google Flights API.
  • amadeus-cloud (npm): replaces the Amadeus SDK (flight search). Amadeus Self-Service keys stopped working in July 2026; flightOffersSearch.get/post return Amadeus-shaped offers again.
  • app-store-scraper-cloud (npm): replaces app-store-scraper. A reliable reviews(): no 403 or "Unexpected token <" errors, more than 500 reviews; same API.
